Mobile Programming — Project

Tim Pengembang Semester 4 — 2026

Flutter App — REST API Integration

Mata kuliah Mobile Programming — Project (MOP/P) adalah puncak dari pembelajaran Mobile Programming, di mana seluruh konsep Flutter yang telah dipelajari diimplementasikan dalam sebuah proyek aplikasi mobile yang utuh dan fungsional. Kami membangun sebuah aplikasi mobile Flutter yang terhubung secara penuh dengan backend REST API.

1. Arsitektur Aplikasi: State Management dengan Provider

Untuk mengelola state aplikasi yang kompleks secara efisien, kami mengadopsi pola arsitektur MVVM (Model-View-ViewModel) dengan menggunakan package Provider sebagai solusi state management:

  • ChangeNotifier: Kelas yang menyimpan state bisnis dan memberitahu listener ketika data berubah.
  • Consumer Widget: Widget yang mendengarkan perubahan dari ChangeNotifier dan merender ulang UI secara otomatis dan efisien.
  • MultiProvider: Menyediakan banyak state sekaligus ke seluruh pohon widget aplikasi dari titik teratas.

2. Integrasi REST API

Aplikasi yang kami bangun mengonsumsi data dari sebuah REST API backend. Kami menggunakan package http dan Dio untuk menangani komunikasi jaringan:

  • HTTP GET: Mengambil daftar data dari server dan menampilkannya dalam ListView.
  • HTTP POST/PUT: Mengirim data form (pendaftaran, login, buat konten baru) ke server menggunakan body JSON.
  • JWT Token Authentication: Menyimpan token autentikasi secara lokal menggunakan SharedPreferences dan mengirimkannya di setiap request yang membutuhkan autorisasi melalui HTTP header.
  • Error Handling: Menampilkan pesan error yang ramah pengguna ketika jaringan tidak tersedia atau server mengembalikan kode error (4xx, 5xx).

3. Penyimpanan Lokal

Kami mengimplementasikan dua mekanisme penyimpanan lokal yang berbeda sesuai kebutuhan:

  • SharedPreferences: Untuk menyimpan data sederhana berpasangan kunci-nilai seperti token login, preferensi tema, dan data profil pengguna yang di-cache.
  • SQLite (via package sqflite): Untuk menyimpan data terstruktur secara lokal, memungkinkan fitur offline-first di mana pengguna tetap dapat melihat konten meski tanpa koneksi internet.

4. UI/UX Berkualitas Tinggi

Di luar fungsionalitas, kami juga memperhatikan aspek tampilan dan pengalaman pengguna:

  • Skeleton Loading: Menampilkan placeholder animasi saat data sedang dimuat dari API, menggantikan loading spinner yang membosankan.
  • Pull-to-Refresh: Memungkinkan pengguna memperbarui data dengan gestur tarik ke bawah yang sudah akrab.
  • Hero Animation: Animasi transisi halus antar halaman menggunakan widget Hero untuk elemen seperti gambar dan ikon yang berpindah layar.
  • Responsive Layout: Memastikan tampilan aplikasi tetap proporsional di berbagai ukuran layar menggunakan LayoutBuilder dan MediaQuery.

5. Testing dan Optimalisasi Performa

Sebelum aplikasi diserahkan, kami melakukan serangkaian pengujian dan optimasi:

  • Widget Testing: Menulis unit test untuk komponen-komponen UI kritis menggunakan package flutter_test.
  • Performance Profiling: Menggunakan Flutter DevTools untuk mengidentifikasi dan memperbaiki jank (frame drop) pada animasi dan scroll.
  • Release Build: Mengompilasi aplikasi ke mode release untuk mengukur performa nyata di perangkat fisik.

Proyek MOP/P ini adalah salah satu pencapaian teknis paling kompleks yang kami kerjakan di Semester 4. Mengintegrasikan frontend mobile, state management, REST API, dan penyimpanan lokal dalam satu aplikasi yang kohesif merupakan pengalaman belajar yang luar biasa berharga.
