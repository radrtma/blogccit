Developing Enterprise Information System using Framework

Tim Pengembang Semester 4 — 2026

CodeIgniter 4 — Enterprise Framework

Mata kuliah Developing Enterprise Information System using Framework (DIS) merupakan salah satu mata kuliah inti di Semester 4 yang membekali mahasiswa dengan kemampuan membangun sistem informasi berskala enterprise menggunakan framework modern. Framework utama yang digunakan adalah CodeIgniter 4 (CI4), sebuah PHP framework ringan berperforma tinggi dengan arsitektur MVC.

1. Arsitektur MVC (Model-View-Controller)

Konsep fundamental yang menjadi dasar dari seluruh pengembangan menggunakan CI4 adalah pola desain Model-View-Controller. Pola ini memisahkan tanggung jawab aplikasi menjadi tiga lapisan terpisah:

  • Model: Menangani seluruh logika data dan komunikasi langsung dengan database MySQL menggunakan Query Builder CI4. Model bertanggung jawab atas validasi data sebelum disimpan.
  • View: Menghasilkan representasi visual (HTML) yang dikirim ke browser. CI4 mendukung pengelompokan view ke dalam folder partials untuk komponen yang dapat digunakan ulang seperti header, navbar, dan footer.
  • Controller: Jembatan antara Model dan View. Controller memproses HTTP request dari pengguna, memanggil method pada Model, lalu mengirimkan data ke View yang sesuai.

2. Routing dan RESTful Endpoints

CI4 memiliki sistem routing yang sangat fleksibel melalui file app/Config/Routes.php. Kami mempelajari cara mendefinisikan:

  • Resource Routes untuk CRUD otomatis dengan satu baris kode menggunakan $routes->resource('posts').
  • Named Routes untuk mempermudah pembuatan URL secara dinamis di dalam View.
  • Route Grouping dengan middleware (Filters) untuk mengamankan grup rute tertentu, misalnya seluruh rute /dashboard/* yang membutuhkan autentikasi.

3. Database Migration & Seeding

Mengelola skema database dalam tim yang beranggotakan empat orang secara manual seringkali menimbulkan konflik. Kami belajar mengatasi ini dengan:

  • Database Migrations: Mendefinisikan struktur tabel (buat, ubah, hapus kolom) dalam file PHP yang dikontrol versi. Setiap anggota tim dapat mensinkronisasi skema database dengan satu perintah: php spark migrate.
  • Database Seeding: Mengisi tabel dengan data dummy awal secara otomatis melalui perintah php spark db:seed, sangat berguna untuk keperluan testing dan demonstrasi.

4. Autentikasi & Middleware (Filters)

Keamanan sistem informasi enterprise adalah prioritas utama. Kami merancang sistem autentikasi berbasis session dan menggunakan fitur Filters CI4 sebagai middleware untuk:

  • Memeriksa status login sebelum mengizinkan akses ke halaman sensitif seperti dashboard admin.
  • Melindungi endpoint dari serangan CSRF (Cross-Site Request Forgery) menggunakan token bawaan CI4.
  • Redirect otomatis pengguna yang belum login ke halaman login.

5. Integrasi dengan Frontend

Selain logika backend, kami juga mempelajari cara mengintegrasikan aset frontend (CSS, JavaScript, gambar) secara terstruktur ke dalam direktori public/assets/ CI4. Pemisahan ini memastikan bahwa file PHP aplikasi tidak dapat diakses langsung dari web, meningkatkan keamanan secara signifikan.

Secara keseluruhan, mata kuliah DIS memberikan fondasi yang kuat dalam memahami cara kerja sebuah framework MVC backend modern, yang menjadi bekal penting sebelum beralih ke teknologi dan arsitektur yang lebih kompleks di semester berikutnya.
