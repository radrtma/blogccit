Mobile Programming

Tim Pengembang Semester 4 — 2026

Flutter — Cross-Platform Mobile

Mata kuliah Mobile Programming (MOP) memperkenalkan kami pada dunia pengembangan aplikasi perangkat mobile modern. Framework utama yang digunakan adalah Flutter — framework cross-platform buatan Google yang menggunakan bahasa pemrograman Dart. Flutter memungkinkan pengembangan satu codebase yang dapat dikompilasi menjadi aplikasi native berkualitas tinggi untuk Android dan iOS.

1. Bahasa Dart dan Paradigma OOP

Sebelum masuk ke Flutter, kami mempelajari bahasa Dart sebagai fondasinya. Dart adalah bahasa yang strongly-typed, mendukung pemrograman asinkron dengan async/await, dan berorientasi objek penuh. Konsep-konsep yang kami pelajari meliputi:

  • Null Safety: Fitur utama Dart modern yang mencegah null reference errors pada saat kompilasi.
  • Class & Inheritance: Mendefinisikan model data dan komponen UI menggunakan prinsip OOP.
  • Futures & Streams: Menangani operasi asinkron seperti pemanggilan API dan pembacaan data real-time.

2. Widget Tree dan Reactive UI

Inti dari Flutter adalah konsep Widget Tree. Semua yang tampil di layar adalah widget — dari tombol, teks, hingga layout kompleks. Kami mempelajari dua jenis widget utama:

  • StatelessWidget: Widget yang bersifat immutable (tidak berubah). Digunakan untuk komponen UI yang tampilannya tidak bergantung pada perubahan data, seperti label statis atau ikon.
  • StatefulWidget: Widget yang memiliki state internal yang dapat berubah. Ketika state berubah (melalui setState()), Flutter secara otomatis merender ulang bagian UI yang terpengaruh secara efisien.

3. Layout System Flutter

Flutter menggunakan sistem layout berbasis constraint yang kuat dan fleksibel. Kami menguasai berbagai widget layout esensial:

  • Row & Column: Menata widget secara horizontal dan vertikal.
  • Stack: Menumpuk widget di atas satu sama lain, berguna untuk overlay dan efek visual.
  • ListView & GridView: Menampilkan daftar data yang panjang dengan scrolling yang efisien.
  • Expanded & Flexible: Membagi ruang yang tersedia secara proporsional di antara beberapa widget dalam Row atau Column.

4. Navigasi dan Routing

Dalam aplikasi multi-halaman, manajemen navigasi sangat penting. Kami mempelajari:

  • Navigator 2.0 dan package GoRouter untuk routing deklaratif yang lebih modern dan mudah dikelola.
  • Pengiriman data antar halaman melalui route arguments.
  • Implementasi Bottom Navigation Bar dan Drawer sebagai pola navigasi utama yang familiar bagi pengguna mobile.

5. Penanganan Sensor dan Platform Channel

Kami juga diperkenalkan pada kemampuan Flutter dalam mengakses fitur hardware perangkat melalui Platform Channel, seperti kamera, GPS, dan akselerometer, menggunakan package populer seperti camera, geolocator, dan sensors_plus.

Mata kuliah Mobile Programming ini membuka perspektif baru dalam pengembangan perangkat lunak, di mana kami tidak hanya berfokus pada web, tetapi juga mampu merancang pengalaman pengguna yang intuitif dan berkualitas tinggi di platform mobile.
