Developing Enterprise Information System using Framework — Project

Tim Pengembang Semester 4 — 2026

Full-Stack Project — CI4 Social Blog

Mata kuliah Developing Enterprise Information System using Framework — Project (DIS/P) adalah kelanjutan langsung dari mata kuliah DIS. Di sini, kami menerapkan seluruh teori yang telah dipelajari ke dalam sebuah proyek nyata, kolaboratif, dan berskala penuh: sebuah platform blog sosial berbasis web yang dikembangkan dari nol menggunakan CodeIgniter 4.

1. Proyek: CI4 Social Blog

Proyek yang dikerjakan adalah CI4 Social Blog — sebuah platform blog dengan fitur-fitur lengkap layaknya aplikasi web nyata, meliputi:

  • Sistem registrasi dan autentikasi pengguna berbasis session yang aman.
  • Halaman dashboard untuk membuat, mengedit, dan menghapus postingan blog.
  • Sistem komentar interaktif pada setiap postingan.
  • Fitur upload gambar untuk thumbnail postingan dengan validasi tipe dan ukuran file.
  • Halaman profil pengguna dengan kemampuan mengubah data dan foto profil.
  • Fitur pencarian postingan secara real-time.

2. Manajemen Kolaborasi dengan Git

Proyek ini dikerjakan secara tim oleh empat orang. Untuk menghindari konflik kode, kami menerapkan alur kerja Git yang terstruktur:

  • Feature Branching: Setiap fitur dikembangkan di branch terpisah (misalnya feature/auth, feature/comment) sebelum di-merge ke branch utama.
  • Pull Request & Code Review: Setiap perubahan harus melalui review dari minimal satu anggota tim lain sebelum dapat di-merge.
  • Commit Convention: Menggunakan konvensi pesan commit yang jelas seperti feat:, fix:, refactor: untuk keterbacaan riwayat proyek.

3. Struktur Direktori & Clean Architecture

Kami menerapkan prinsip-prinsip clean architecture dalam menyusun struktur proyek CI4:

  • Memisahkan logika bisnis ke dalam Service Layer yang dipanggil oleh Controller, agar Controller tetap tipis dan mudah diuji.
  • Menggunakan Helper functions CI4 untuk utilitas umum seperti format tanggal dan manipulasi string.
  • Mengelola konfigurasi sensitif (database credentials, base URL) melalui file .env yang tidak dikontrol versi (ditambahkan ke .gitignore).

4. Validasi Form & Keamanan

Keamanan adalah aspek krusial dalam proyek enterprise. Kami mengimplementasikan:

  • Server-side Validation menggunakan Validation Library bawaan CI4 untuk memvalidasi setiap input pengguna sebelum diproses.
  • CSRF Protection pada setiap form POST untuk mencegah serangan Cross-Site Request Forgery.
  • Password Hashing menggunakan fungsi password_hash() PHP dengan algoritma BCRYPT sebelum menyimpan ke database.
  • XSS Filtering pada output data yang bersumber dari input pengguna.

5. Deployment ke Hosting

Sebagai bagian dari pengalaman nyata, kami mempelajari cara men-deploy aplikasi CI4 ke server hosting shared. Langkah-langkah yang kami pelajari meliputi konfigurasi .htaccess, pengaturan base URL untuk lingkungan produksi, dan manajemen file .env yang berbeda antara development dan production.

Proyek DIS/P ini menjadi bukti nyata kemampuan kami bekerja dalam tim untuk menghasilkan sebuah produk perangkat lunak yang fungsional, aman, dan siap digunakan. Pengalaman ini sangat berharga sebagai persiapan memasuki dunia kerja profesional.
